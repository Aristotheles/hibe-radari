# Lovable arayüz çalışması için devir

Kaynak depo: https://github.com/Aristotheles/hibe-radari

Bu proje Python backend + sade HTML/CSS/JavaScript kullanır. Başlangıç ekranı web/index.html, görünüm web/style.css, davranış web/app.js içindedir. İş kuralları Python backend'dedir. README.md, MVP.md ve docs/SECURITY.md kapsamın kaynaklarıdır.

Lovable mevcut GitHub deposunu doğrudan içe aktarmayı desteklemez:
https://docs.lovable.dev/integrations/github
Depo bağlantısı otomatik içe aktarma veya bu depoyla senkronizasyon anlamına gelmez. Tasarım prototipi hazırlanırsa çıktısı mevcut projeye ayrıca uyarlanmalı ve yerelde doğrulanmalıdır.

## Lovable'a verilecek başlangıç istemi

Hibe Radarı için Türkçe, mobil uyumlu bir arayüz prototipi geliştir. Kaynak ve davranış referansı https://github.com/Aristotheles/hibe-radari; README.md, MVP.md, docs/SECURITY.md ve web/ dosyalarını incele. Bağlantıdan dosyalara erişemiyorsan erişemediğini belirt ve ilgili dosyaların eklenmesini iste; okumuş gibi davranma.

Üç ekranı koru: Fırsat radarı, Aboneliğim, Yönetim paneli. Radar ekranında arama, başvuru yolu filtresi, ilan kartları, uygunluk/belirsizlik ve son tarih bilgisi olmalı. Abonelikte tema tercihleri ve açık opt-in; yönetimde kanıt inceleme, onay kuyruğu, kaynak sağlığı ve büyüme sayıları korunmalı.

Bu çalışma yalnız arayüz prototipidir. Kurgusal ilanlarda DEMO etiketi görünür kalsın. Gerçek kaynak/ilan/URL/kanıt uydurma; 30 kaynak hedefini azaltma. Gerçek Google/Firebase/Gemini/SMTP bağlantısı kurma; anahtar isteme; veritabanı oluşturma veya yayınlama. API ve iş kurallarını değiştirme. Python backend'in Lovable önizlemesinde çalıştığını iddia etme; önizleme için yalnız açıkça etiketlenmiş yerel örnek veri kullan. Mevcut HTML/CSS/JS uygulamasına aktarılabilecek tasarım ve bileşen düzenini ayrıca açıkla.
